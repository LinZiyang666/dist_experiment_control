## 2. Rotation flow

CLI (cluster_retire.go): `--compromised` (advisory printer) + `--require-credential-rotation` (requires --compromised; typed-confirm + persistent alert + banner) + `--secrets-dir` (reads PUBLIC fps from the LOCAL host only). Branching: require-without-compromised→usage error; flags absent→BYTE-IDENTICAL existing path; require set→ (a) callAdmin(OpClusterRetire, Confirmed:false) to surface the F==0 QuorumProj, (b) one `confirmTypedNodeID` (never --yes, refuses non-TTY; subsumes the F==0 confirm), (c) drive retire Confirmed:true, on success raise the tracking alert (OpClusterAlertRaise, manual/severe, label `credrot:<node>`) — **if the alert raise fails, still print the guide + banner (banner is the floor)** — (d) print guide + non-green banner, **exit 0**. `--compromised`-only = existing retire + print guide (no alert/confirm).

Per-secret paths (§2.2): account.nk (CRITICAL, shared) + cluster-CA + route-key → GUIDED CHECKLIST (OOB, operator's own PKI; printer shows the public A…/ca-sha256 as "verify your NEW differs — THIS host only"); tunnel-cert (per-node, OPTIONAL DiD) → ONLINE reuse RotateTunnelCert (per surviving broker: transfer-leader --wait + rotate-tunnel-cert <self> --cert-fp); broker.nk/node-ident.nk → EXCLUDED (printed rationale). Printer (`printCredentialRotationGuide`, read-only, secret-free): header (retire≠trust-revocation, NOT-SAFE until rotated+cleared), advisory local fps, Step A (OOB reseed CRITICAL, verbatim runbook §2.1 + "tether NEVER copies private keys"), Step B (tunnel-cert optional online), exclusions+caveats (old-JWT-TTL, proxy-PSK), when-done (`tether alert clear manual:credrot:<node>`). Non-green banner: no done/safe/secure/complete wording.

## 3. Rejection-table guards

**#2 structural impossibility**: the flow = a cmd/tether printer + RotateTunnelCert (fp string, self-host hot-swap) + alert text. Only the 4 sanctioned public/hash/perm helpers touch secrets. Guard `TestC7RotationNoPrivateKeyExfilStatic` (allow-list token-scan over cluster_rotation.go; forbid other secret reads + any write/copy/publish/exec of key paths + importing a NATS-publish/remote-write primitive; scoped to the rotation cmd file, NOT the drill). **#5 explicit INCOMPLETE state**: persistent severe manual alert (reconciler never touches manual) + non-green banner + typed-confirm + advisory-only fp + old-JWT-TTL caveat; manual severe is banner-only, never hard-gates writes. **secret-free output**: guard `TestC7RotationGuidePrintsNoSecrets` (canary fixture; no private bytes/PEM/seed in output or alert; public A…/ca-sha256/tunnel-fp present).
