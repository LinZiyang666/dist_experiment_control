## 0. Objective + what C5 closes

C5 makes the P13 session proxy **cluster-aware + HA**: the proxy CONTROL plane (enable, subscriber set, keyset generation, per-agent `__proxy__` allocation) becomes **Raft-committed (majority-write)**, while the DATA plane stays **leader-decoupled** — `/sub/<token>` is served by ANY broker + returns the AUTHORITATIVE home, and a dead proxy home **auto-rehomes** via the D6 epoch ladder. **Re-opens the D9 cluster-mode proxy-OFF gate** (6 sites) via the Raft control plane.

**建议4 acceptance (verbatim intent):** under cluster, `proxy on/sub/status` work; killing the proxy home broker ⇒ the subscription briefly vanishes OR auto-switches to a new home, WITHOUT `proxy off/on`; `proxy status --cluster` explains each agent's readiness. Closes success metric **#4** + the C5 gap rows (proxy-OFF-in-cluster, no proxy home failover, no degraded surfacing).

## 2. Control plane into Raft

New ops (`command.go knownOps`, all `genericExecApplier`, all-literal leader-baked, baked WHERE guards only — no Apply CHECK/UNIQUE so POISON-safe; uniqueness prechecked leader-side):
- **`OpProxySetEnabled`** — `UPDATE sessions SET proxy_enabled, proxy_ha_policy, proxy_epoch=cur+1 WHERE sid AND state='ACTIVE'` change-gated (identical re-propose = no-op, no double epoch bump). `session.PlanProxySetEnabled`.
- **`OpProxySubCreate`** — `INSERT proxy_subscribers(token_hash, psk, cipher, state='ACTIVE', created_at)` + `proxy_epoch` bump (single Command). `proxysub.PlanCreate`. BROADCAST+leader-only. Leader prechecks `(sid,name)` ACTIVE-uniqueness → `ErrNameTaken` before propose.
- **`OpProxySubRevoke`** — `UPDATE proxy_subscribers SET state='REVOKED' WHERE sid,name,ACTIVE` + epoch bump. `proxysub.PlanRevoke`. queue-group + proposeOrForward.
- **`OpProxyAllocate`** — INSERT the `__proxy__` `port_allocations` row (`home_broker=lit`, `epoch=0`, leader-baked free port + token_hash). `port.PlanAllocateProxy` (prechecks per-`(sid,nid)` uniqueness, NOT per-`(sid,name)`). Distinct op for DIFF-1.
- **Reuse** `OpPortReassignHome` (D6 rehome), `OpPortFree` (proxy-off/sub teardown), `OpClusterOpStart` (C4 force-home incident).
Plan helpers in the mutator packages (L-2: `internal/cluster` must not import proxysub/session/port). `dispatchForward` cases for the queue-group verbs.
