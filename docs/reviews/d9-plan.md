3. **Multi-broker NATS `status` aggregation** — the ctl/NATS `cluster status` view fans `cluster-health`/cursor RPCs to ALL reachable brokers (the D8b `SubscribeClusterHealth` broadcast already exists) and aggregates per-node `reachable`/`reach_source`/`applied-lag`/`role`/`phase` into the D7 `--json` schema (`schema_version` bumped). exit 2 (`quorum_lost`) still only from a **majority** of self-reports, never "no one answered" (the D7 false-quorum-lost guard preserved).
